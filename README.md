# Frontend AgroAir

Frontend canônico do projeto.

## Arquivos principais
- `agroair_v2_verde.html` — catálogo público
- `agroair.js` — lógica do catálogo
- `Login.html` — login/entrada
- `login.js` — lógica do login
- `Painel_admin.html` — painel administrativo
- `painel.js` — lógica do painel admin

## Observação
A raiz do projeto mantém apenas páginas pequenas de redirecionamento para compatibilidade com caminhos antigos.

Se for editar o frontend, edite aqui.
